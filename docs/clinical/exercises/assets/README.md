# 운동별 상세 해석 Asset

이 폴더는 `docs/clinical/exercises/*.md`에서 사용하는 상세 설명용 그림을 보관한다.

권장 하위 구조:

```text
assets/
  squat/
  lunge/
  pike_pushup/
  plank_shoulder_tap/
```

대표 수행 사진은 `docs/practical_protocols/assets/`에 유지한다. 이 폴더에는 관절각 도식,
보상 패턴 예시, landmark confidence 비교, camera-view 비교처럼 상세 해석을 돕는 그림만 둔다.
