# Exercise Authoring Examples

This directory contains git-tracked examples generated by the exercise authoring
notebook. These files demonstrate the split-YAML bundle layout and are not
canonical exercise definitions.

Local notebook exports belong under:

```text
data/processed/authoring_drafts/<exercise_id>/
```

Commit-ready examples belong under:

```text
data/examples/exercise_authoring/<exercise_id>/
```

To load the `draft_squat` example through the existing pipeline loader, use:

```yaml
exercise_definition:
  exercise_id: draft_squat
  definitions_dir: data/examples/exercise_authoring/draft_squat/data/definitions/exercises
```

The loader resolves the sibling analysis, performance, and camera YAML files
inside the same bundle root.
